# Instructions d'utilisation

Pour compiler et exécuter les tests, il faut taper les commandes:

```bash
make
./test.sh
```

# Organisation du code source

- `fonction.h` : contient les déclarations de nos fonctions.
- `fonction.cpp` : contient les définitions de nos fonctions de base.
- `travail.cpp` : contient les fonctions ajoutées lors de ce projet.
- `comparaison_base_task2.png` : est une synthèse des resultats qu'on a obtenus.
